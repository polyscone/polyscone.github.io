Tree-Walk Interpreter in JavaScript (2025 Archive)

A 2025 project building a small tree-walk interpreter in JavaScript without AI assistance, over roughly two hours. The implementation scans source text into tokens, uses a Pratt parser to build an abstract syntax tree, and evaluates that tree directly. It supports arithmetic, unary prefix and postfix operators, parenthesised groups, expression statements, variables, blocks, returns and function calls.

The series explains how operator precedence shapes an expression tree and how evaluating that tree produces a result. Function execution and returns from nested blocks demonstrate how the interpreter handles control flow. The compiler from scratch archive covers a separate implementation with type checking and native machine-code output.
