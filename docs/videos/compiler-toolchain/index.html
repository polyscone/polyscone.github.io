Compiler Toolchain Development

A series of unedited programming sessions building a native compiler toolchain from scratch in Go, without AI assistance or reliance on LLVM. The project covers x86-64 machine-code encoding, ELF and COFF object files for use with external linkers, and an assembler frontend. The recordings include implementation, validation, performance work, debugging and design changes.

This page collects all videos in recording order. The x86-64 encoder, ELF object writer, COFF object writer and assembler pages group the videos by component.

Watch the Compiler Toolchain Development playlist on YouTube

Toolchain subseries

  1. x86-64 Encoder

    Turning instructions into bytes: operand matching, ModR/M and SIB addressing, legacy/REX, VEX and EVEX encodings, validation and fixups.

  2. ELF Object Writer

    Packaging generated code into ELF relocatable objects, with sections, string tables, symbols, relocations and .bss support.

  3. COFF Object Writer

    Writing Windows COFF object files, with section headers, symbols, relocations, long names and relocation overflow support.

  4. Assembler

    Building an assembly-language frontend in Go: scanning, comment trivia, expression parsing, declarations, memory operands and diagnostics.
